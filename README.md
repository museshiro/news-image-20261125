## How it works

`entry.png` (1024×1024, drawn with a deterministic Python/PIL renderer —
`render.py`, kept beside the repo) is copied byte-for-byte to
`/output/entry.png` by `main.ts`. No network, no randomness: every run
produces the same bytes.
